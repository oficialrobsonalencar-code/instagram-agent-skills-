# Chapter 1: Introdução

## Core Idea
O sucesso de Reels depende de entender os 3 pilares: hook inicial, valor do conteúdo e engajamento comunitário.

## Frameworks Introduced

### The Viral Loop Framework
**When to use**: Sempre criando conteúdo para maximizar alcance

**How it works**:
1. **Hook** (0-3s): Capture atenção
2. **Value** (3-15s): Entregue a mensagem principal
3. **Curiosity** (15-20s): Termine com pergunta
4. **CTA** (20-30s): Incentive ação

### Hook Formula Patterns
- Contrarian: "A maioria faz ERRADO"
- Question: "Você sabia que...?"
- Problem/Solution: "Cansado de...?"
- Number: "5 segredos de..."
- Before/After: "Antes x Depois"

## Key Takeaways
1. O hook é mais importante que o CTA
2. Conteúdo educativo gera mais saves
3. Perguntas atraem mais comentários
