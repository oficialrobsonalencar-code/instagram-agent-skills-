# CONTROLE DE FONTES E AUTORIZACAO | REGRA OBRIGATORIA
Data: 12/11/2026

## REGRA ZERO: ENCONTRAR UM ARQUIVO NAO AUTORIZA SEU USO
A existencia de arquivos, anexos, imagens, videos, logos, referencias, modelos, documentos, pastas de perfil, mapas, trabalhos antigos ou sessoes anteriores NUNCA constitui autorizacao para reutilizar esses materiais. Esta regra vale para todos os agentes e modelos.
Uma lista de arquivos, busca, mapa operacional, Graphify, skill ou nome contendo "referencia" serve para localizar, nao para conceder uso.

## FONTES PERMITIDAS POR TAREFA
1. Somente arquivos que o usuario indicar explicitamente para O PEDIDO ATUAL entram na lista de materiais permitidos.
2. Sem arquivo indicado, gerar material original de acordo com o pedido, sem copiar composicoes ou textos historicos.
3. Arquivos tecnicos de skills e scripts podem ser consultados para executar, mas nao transformados em arte ou post.
4. Itens em 00-usuario/perfil estao guardados para o usuario; nao sao biblioteca de uso automatico. Isso inclui foto, logo provisorio e referencias.
5. Nao usar nenhum arquivo em I:/_QUARENTENA_IA, nem restaurar outputs descartados.
6. Nao presumir que o ultimo arquivo, o ultimo carrossel ou a ultima arte criada eh o arquivo escolhido para o novo pedido.
7. Se a fonte exata nao estiver especificada e for indispensavel, pedir uma confirmacao objetiva ANTES de escolher uma.

## ENTREGA
Antes de produzir, registrar no proprio trabalho: objetivo, fontes expressamente indicadas e fontes nao autorizadas. Nao inventar aprovacao. Nao publicar sem autorizacao expressa para o pacote exato e liberacao manual do bloqueio de seguranca.
