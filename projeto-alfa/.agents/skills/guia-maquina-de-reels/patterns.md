# Patterns — Guia da Máquina de Reels

## Hook Patterns

### Contrarian Hook
**When to use**: Quando tem informação oposta ao comum
```
Exemplo: "A maioria faz ERRADO ao criar Reels de dicas..."
```

### Question Hook
**When to use**: Para provocar curiosidade imediata
```
Exemplo: "Você sabia que 73% das pessoas..."
```

### Problem/Solution Hook
**When to use**: Quando resolver dor específica
```
Exemplo: "Cansado de Reels que não engajam? 3 estratégias..."
```

### Number Hook
**When to use**: Para listas e estruturas claras
```
Exemplo: "5 passos para viralizar seu Reels"
```

## Engagement Techniques

### Comment Bait
**When to use**: Para aumentar interação
- Perguntas abertas no final
- Desafios para o público
- Perguntas que geram identificação

### Save-Worthy Content
**When to use**: Para builds de leads
- Listas teóricas
- Passos práticos
- Templates/fórmulas

### Share Triggers
**When to use**: Para amplificação orgânica
- Informações únicas
- Conteúdo controverso (respeitoso)
- Mensagem que faz pensar
