# Cheatsheet — Guia da Máquina de Reels

## Performance Benchmarks

| Métrica | Bom | Excelente | Ação Recomendada |
|---------|-----|-----------|------------------|
| Retenção 3s | >60% | >75% | Reanalisar hook |
| Retenção 15s | >40% | >55% | Melhorar valor |
| Compartilhamento | >3% | >5% | Acrescentar curiosidade |
| Saves | >5% | >8% | Mais conteúdo prático |

## Quick Decision Table

```
Se Retenção < 40%: Hook fraco → refazer primeiros 3s
Se Shares < 3%: Falta curiosidade → acrescentar pergunta
Se Saves < 5%: Falta valor → mais prático/dica
Se Comentários < 2%: Falta interação → questionar
```

## Timing Cheat Sheet

| Tipo de Conteúdo | Duração Ideal | Foco |
|-----------------|---------------|------|
| Dica rápida | 15-20s | Hook + CTA |
| Tutorial | 30-45s | Passo a passo |
| Estatística | 10-15s | Surpresa + fonte |
| Pergunta | 20-30s | Curiosidade + resposta |

## Format Best Practices

1. **Vertical 9:16** (1080x1920)
2. **Legendas em over**: Não cobrir rosto
3. **Transição cada 3-5s** para retenção
4. **Música sem direitos** ou do Instagram
5. **CTA visível** mas não dominante
