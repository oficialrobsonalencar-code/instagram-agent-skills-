## Core Frameworks & Mental Models

### 1. The Viral Loop Framework
Use this when designing Reels content to maximize reach.

**When to apply**: Every Reel you want to go viral

**How it works**:
1. **Hook** (0-3 seconds): Grab attention immediately
2. **Value** (3-15 seconds): Deliver the core message
3. **Curiosity** (15-20 seconds): End with a question or teaser
4. **CTA** (20-30 seconds): Prompt action (follow, share, comment)

### 2. Hook Formula Patterns
```
1. Contrarian: "A maioria faz ERRADO"
2. Question: "Você sabia que...?"
3. Problem/Solution: "Cansado de...? Aqui está"
4. Number: "5 segredos de..."
5. Before/After: "Antes x Depois"
```

### 3. Engagement Matrix
**Metric** | **Strategy** | **Target**
-----------|--------------|----------
Views | Hook + Early retention | 1K+
Saves | Educational + Value-packed | 5% of views
Shares | Controversial + Relatable | 3% of views
Comments | Question + Curiosity | 2% of views

### 4. Content Structure Framework
**For Technical/Process Content**:
- Scene 1: Problem introduction (hook)
- Scene 2: Common mistakes
- Scene 3: Step-by-step solution
- Scene 4: Results proof
- Scene 5: CTA + Next tip

## Glossary

**Hook** — Primeiros 3 segundos críticos para retenção
**Viral Loop** — Mecanismo que impulsiona compartilhamento
**Engajamento** — Interações (curtidas, comentários, saves)
**Algoritmo** — Sistema de recomendação do Instagram
**Retention** — Taxa de retenção de espectadores

## Cheat Sheet

| Métrica | Bom | Excelente |
|---------|-----|-----------|
| Retenção 3s | >60% | >75% |
| Retenção 15s | >40% | >55% |
| Compartilhamento | >3% | >5% |
| Saves | >5% | >8% |

### Quick Decision Rules
1. **Se retenção < 40% nos primeiros 15s** → Hook fraco, refazer
2. **Se shares < 3%** → Falta de curiosidade, acrescentar pergunta
3. **Se saves < 5%** → Conteúdo muito entretenimento, focar em valor
