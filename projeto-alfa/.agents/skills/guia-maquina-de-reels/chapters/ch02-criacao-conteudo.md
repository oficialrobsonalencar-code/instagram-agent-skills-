# Chapter 2: Criação de Reels

## Core Idea
A estrutura do conteúdo define a retenção: histórias bem contadas mantêm espectadores até o final.

## Key Concepts

### Content Structure Framework
Para conteúdo técnico/procedimento:
- Scene 1: Apresentação do problema (hook)
- Scene 2: Erros comuns
- Scene 3: Solução passo a passo
- Scene 4: Prova de resultados
- Scene 5: CTA + próximo tip

### Timing Patterns
- 0-3s: Hook de ouro
- 3-8s: Conexão com o público
- 8-20s: Valor principal
- 20-30s: Chamada para ação

## Anti-patterns
- **Hook tardio**: Perder espectadores nos primeiros segundos
- **CTA excessivo**: Parece venda automática
- **Conteúdo genérico**: Não se compartilha

## Key Takeaways
1. Use transições fluidas entre cenas
2. Mantenha texto em tela por 3-4 segundos
3. Legendas precisas aumentam alcance em 15%
